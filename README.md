# Персональний сайт лікаря інтегративної медицини

## Як редагувати контент
- Весь текстовий контент зберігається у Markdown-файлах у папці `content/` (наприклад, `home.md`, `about.md` тощо).
- Зображення додавайте у папку `public/images/` і використовуйте їх у Markdown через стандартний синтаксис: `![alt](../images/your-image.jpg)`.

## Запуск сайту
1. Встановіть залежності:
   ```sh
   npm install
   ```
2. Запустіть сайт у режимі розробки:
   ```sh
   npm run dev
   ```

## Технології
- Vite + React + TypeScript
- react-markdown для рендерингу контенту
- Сучасний дизайн із градієнтним фоном
